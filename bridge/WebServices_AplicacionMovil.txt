Información de Artículo
1 - Descripción: Retorna información de un artículo especifico
Pedido GET
http://{ip}:{puerto}/{sistema}/rest/webservice/articulo/{codigoArticulo}
Parámetros
CódigoArticulo
Respuesta
Código, Descripción, Detalle, Imagen, Marca, Moneda, Precio Lista, propiedades{propiedad,valor}, stockVenta.
Nota: el campo propiedades es  opcional. Las propiedades q pueden ser pasadas como parámetros son las propiedades dinámicas definidas para los artículos. Las mismas se pasan separadas por coma. Consultar dichas propiedades para cada instalación particular.
Ej: http://localhost:8080/BSGestion/rest/webservice/articulo/134
Respuesta: {"codigo":"IC0414644Y06","descripcion":" AUTOESTEREO NOBLEX NXC1039BT ","detalle":" AUTOESTEREO NOBLEX NXC1039BT ","imagen":"","marca":"NOBLEX","moneda":"$","precioLista":1668.6,"propiedades":null,"stockVenta":1.0}
2 - Descripcion: Retorna información particular del artículo enviado como parametro., las opciones pueden ser:
precio|stock|imagen|propiedades|atributos
Pedido GET
http:// {ip}:{puerto}/{sistema}/rest/webservice/ articulo/{codigo}/ {precio|stock|imagen|propiedades|atributos}
ejemplo:
http:// {ip}:{puerto}/{sistema}//rest/webservice/articulo/9789874201355/precio
Respuesta:  {"codigo":"9789874201355","moneda":"$","precioLista":12500.0}
Listado de Artículos
Descripcion: Retorna un listado con alguna de las propiedades de aquellos artículos q tuvieron una modificación posterior a la fecha y hora indicados. Las propiedades disponibles son precio, stock e imagen.
Pedido GET
http:// {ip}:{puerto}/{sistema}/rest/webservice/articulos/{precio|stock|imagen|propiedades|atributos}/{anio}/{mes}/
{dia}/{HHmm} /{pagina}
Parámetros
Tipo de dato a obtener: precio, stock, imagen, propiedades, atributos
Anio, mes, dia, HHmm: fecha a partir de la que se realiza la consulta
Respuesta
Tipo de dato = precio -> código de artículo, moneda, precio lista
Tipo de dato = stock -> código de artículo, stock venta
Tipo de dato = imagen -> código de artículo, imagen
Tipo de dato = propiedades -> retorna todas las propiedades del articulo
Tipo de dato = atributos -> retorna solo los atributos adicionales del articulo
Nota: Cantidad máxima 100 registros
Ej: http://localhost:8080/BSGestion/rest/webservice/articulos/precio/2018/03/29/0000/1
Respuesta:
[{"codigo":"885911386609","moneda":"$","precioLista":3307.3},{"codigo":"885911106771","moneda":"$","precioLista":2092.38},{"codigo":"885911106627","moneda":"$","precioLista":4389.64},{"codigo":"885911217132","moneda":"$","precioLista":9840.67},{"codigo":"885911144100","moneda":"$","precioLista":3417.22}]

Realizar Reserva
Pedido POST
http://{ip}:{puerto}/{sistema}/rest/webservice/comprobante/reserva
Parámetros
Listado de Comprobantes: [comprobantes] Listado con reservas a agregar al sistema
Empresa: [empresa] Codigo de empresa
Código de Reserva ver
Listado de Pedidos: : [pedidos] Lista con los aticulos solicitados
Código de Artículo : [codigo] código del articulo, Cantidad Solicitada : [cantidad]
Ejemplo
{"comprobantes":[{"empresa":"1","pedidos":[{"codigo":"9789505115952","cantidad":"1"},{"codigo":"9783852721286","cantidad":"1"},{"codigo":"9509216461","cantidad":"1"}]}]}
Respuesta
Código Operación
Mensaje Operación
Posibles Códigos Operación
0x0001 -> Operación realizada con éxito
0x0002 -> Lista de pedidos vacía
0x0003 -> Código/s de producto invalido/s: “323”,”432”
0x0004 -> No se pudo realizar la reserva, motivos internos BSGestion
0x0005 -> Cliente/Usuario invalido
