1. Autenticación
Todas las solicitudes deben incluir un Bearer Token estático en el encabezado HTTP. Cada sistema externo recibe un token
único asignado por el administrador de BSGestion.
Encabezado requerido
Nombre Valor
Authorization Bearer <token>
Ejemplo
GET /api/productos Authorization: Bearer a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4
Respuesta con token inválido — HTTP 401
{ "error": "Token inválido o expirado" }

GET /api/productos— Lista paginada de productos
Devuelve una lista paginada de productos. El contenido de cada registro se controla con el parámetro campos.
Parámetro Ubicación Tipo Requerido Descripción
campos query String No Campos a incluir, separados por coma. Por defecto: id,
codigo, descripcion.
pagina query Integer No Número de página (base 0). Por defecto: 0. Cada página
devuelve hasta 50 registros.
busqueda query String No Texto libre para filtrar por descripción del producto (búsqueda
parcial).
{
"resultado": "ok",
"pagina": 0,
"cantidad": 50,
"datos": [ { .// }, { .// } ]
}
GET /api/productos/{codigo}— Producto individual
Devuelve los datos de un único producto identificado por su código interno.
Parámetro Ubicación Tipo Requerido Descripción
codigo path String Sí Código del producto tal como está registrado en el sistema.
campos query String No Campos a incluir, separados por coma. Por defecto: id, codigo,
descripcion.
HTTP 200 — Encontrado
{
"resultado": "ok",
"datos": {
"id": 1,
"codigo": "001.001.0001",
.//
}
}
HTTP 404 — No encontrado
{
"resultado": "not_found",
"mensaje": "Producto no
encontrado: CODIGO"
}
Campos siempre presentes
id y codigo se incluyen en toda respuesta independientemente de lo especificado en el parámetro campos. El
Content-Type de todas las respuestas es application/json; charset=utf-8.

3. Campos disponibles
El parámetro campos acepta cualquier combinación de los nombres listados a continuación, separados por coma. Los
nombres son case-sensitive.
Ejemplo: campos=codigo,descripcion,precioVenta,moneda,stock,marca,categoria
Identificación
Campo Tipo Descripción
id Long Identificador interno del producto
codigo String Código alfanumérico interno
descripcion String Nombre / descripción del producto
detalle String Descripción ampliada
codigoBarras String Código de barras unitario (cantidad = 1)
codigosBarras Array Lista completa de códigos de barras con cantidad asociada
codigoArba String Código ARBA / nomenclador fiscal
fichaTecnica String Ficha técnica del producto
Precios
Campo Tipo Descripción
precioLista Double Precio de lista sin IVA
precioVenta Double Precio de venta con IVA
precioVentaSIVA Double Precio de venta sin IVA con descuento habitual aplicado
precioCompra Double Precio de compra
precioListaCompra Double Precio de lista de compra
precioCosto Double Precio de costo
precioCostoConIVA Double Precio de costo con IVA incluido
moneda String Símbolo de la moneda (ej: $, USD)

Campo Tipo Descripción
stock Double Stock disponible total (suma de todos los depósitos activos)

stockOptimo Double Stock óptimo de reposición configurado
Consideración de rendimiento — campo stock
Incluir stock genera una consulta adicional a la base de datos por cada producto de la lista. Para consultas
masivas de catálogo donde el stock no es necesario, se recomienda omitirlo y consultarlo individualmente cuando
sea preciso.

4. Ejemplos de uso
Ejemplo 1 — Catálogo básico (campos por defecto)
Cuando se omite el parámetro campos, se devuelven id, codigo y descripcion.
GET https://[servidor]/BSGestion/api/productos Authorization: Bearer <token>
{
"resultado": "ok",
"pagina": 0,
"cantidad": 2,
"datos": [
{ "id": 1, "codigo": "001.001.0001", "descripcion": "Tornillo 6x30" },
{ "id": 2, "codigo": "001.001.0002", "descripcion": "Tornillo 8x50" }
]
}

5. Códigos de error
La API utiliza códigos de estado HTTP estándar. En caso de error, la respuesta siempre incluye los campos resultado y
mensaje.
Código Estado Descripción
200 OK Solicitud procesada correctamente.
400 Bad Request Parámetro inválido o malformado. Revisar los valores enviados.
401 Unauthorized Token ausente, inválido o expirado. Verificar el header Authorization.
404 Not Found El producto especificado no existe en el sistema.
500 Internal Server Error Error interno del servidor.
Estructura de respuesta de error
{
"resultado": "error" | "not_found",
"mensaje": "Descripción detallada del problema"
}
